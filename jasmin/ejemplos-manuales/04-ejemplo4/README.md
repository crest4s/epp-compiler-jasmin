# Ejemplo 4: Operación Lógica

## Descripción
Evalúa una expresión lógica (5 > 3 AND 10 < 20) y muestra el resultado (true).

## Código de Alto Nivel
```java
public class OperacionLogica {
    public static void main(String[] args) {
        boolean resultado = (5 > 3) && (10 < 20);
        System.out.println(resultado);
    }
}
```

## Salida Esperada
```
true
```
