# Resultado de Ejecución - Ejemplo 6: IF Anidados

## Comando de ejecución
```bash
java IfAnidados
```

## Salida del programa
```
Mayor que 10
Menor que 20
```

## Descripción
El programa evalúa el valor 15 con condicionales anidados:
- Primero verifica si es mayor que 10 (imprime "Mayor que 10")
- Luego verifica si es menor que 20 (imprime "Menor que 20")

Demuestra el uso de saltos condicionales y etiquetas en Jasmin.
