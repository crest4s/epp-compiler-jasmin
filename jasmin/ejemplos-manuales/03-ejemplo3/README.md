# Ejemplo 3: Multiplicar Dos Números Enteros

## Descripción
Multiplica dos números enteros (7 * 8) y muestra el resultado (56).

## Código de Alto Nivel
```java
public class Multiplicacion {
    public static void main(String[] args) {
        int a = 7;
        int b = 8;
        int resultado = a * b;
        System.out.println(resultado);
    }
}
```

## Salida Esperada
```
56
```
