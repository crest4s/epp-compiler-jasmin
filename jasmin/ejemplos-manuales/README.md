# Ejemplos Jasmin - Práctica 3

Esta carpeta contiene todos los ejemplos de código Jasmin requeridos por el enunciado.

## Estructura

### Ejemplos Proporcionados (1-2)
- `ejemplo1/` - Programa principal vacío
- `ejemplo2/` - Mostrar cadena de texto

### Ejemplos a Desarrollar (3-12)
- `ejemplo3/` - Multiplicar dos números enteros y mostrar resultado
- `ejemplo4/` - Mostrar resultado de operación lógica
- `ejemplo5/` - Concatenar cadena y número, mostrar resultado
- `ejemplo6/` - IF anidados con resultados
- `ejemplo7/` - Bucle FOR
- `ejemplo8/` - Bucle WHILE
- `ejemplo9/` - Función sin parámetros ni retorno
- `ejemplo10/` - Función que devuelve un entero
- `ejemplo11/` - Función con un parámetro
- `ejemplo12/` - Función con varios parámetros

## Formato de cada ejemplo

Cada carpeta contiene:
- `alto_nivel.txt` - Código en lenguaje de alto nivel (pseudocódigo/E++)
- `codigo.j` - Código Jasmin equivalente
- `ejecucion.txt` - Salida esperada al ejecutar

## Compilar y ejecutar

```bash
# Compilar archivo Jasmin
java -jar ../../Jasmin/jasmin-2.4/jasmin.jar codigo.j

# Ejecutar (sustituir NombreClase por el nombre de la clase)
java NombreClase
```
