# Ejemplo 9: Función Sin Parámetros Ni Retorno

## Descripción
Define y llama a una función que no recibe parámetros ni devuelve valor.

## Código de Alto Nivel
```java
public class FuncionSimple {
    public static void main(String[] args) {
        saludar();
    }
    
    public static void saludar() {
        System.out.println("Hola desde la función");
    }
}
```

## Salida Esperada
```
Hola desde la función
```
