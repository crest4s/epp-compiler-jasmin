# Ejemplo 7: Bucle FOR

## Descripción
Implementa un bucle FOR que imprime números del 1 al 5.

## Código de Alto Nivel
```java
public class BucleFor {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}
```

## Salida Esperada
```
1
2
3
4
5
```
