# Ejemplo 5: Concatenar Cadena y Número

## Descripción
Concatena una cadena de texto con un número y muestra el resultado.

## Código de Alto Nivel
```java
public class Concatenacion {
    public static void main(String[] args) {
        String texto = "El resultado es: ";
        int numero = 42;
        String resultado = texto + numero;
        System.out.println(resultado);
    }
}
```

## Salida Esperada
```
El resultado es: 42
```
