# Ejemplo 10: Función Que Devuelve Un Entero

## Descripción
Define y llama a una función que devuelve un entero.

## Código de Alto Nivel
```java
public class FuncionConRetorno {
    public static void main(String[] args) {
        int resultado = calcular();
        System.out.println(resultado);
    }
    
    public static int calcular() {
        return 42;
    }
}
```

## Salida Esperada
```
42
```
