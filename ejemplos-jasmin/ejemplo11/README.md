# Ejemplo 11: Función Con Un Parámetro

## Descripción
Define y llama a una función que recibe un parámetro entero.

## Código de Alto Nivel
```java
public class FuncionConParametro {
    public static void main(String[] args) {
        mostrarNumero(25);
    }
    
    public static void mostrarNumero(int num) {
        System.out.println("El número es: " + num);
    }
}
```

## Salida Esperada
```
El número es: 25
```
