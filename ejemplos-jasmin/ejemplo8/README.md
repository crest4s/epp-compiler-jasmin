# Ejemplo 8: Bucle WHILE

## Descripción
Implementa un bucle WHILE que imprime números mientras sean menores que 5.

## Código de Alto Nivel
```java
public class BucleWhile {
    public static void main(String[] args) {
        int contador = 0;
        while (contador < 5) {
            System.out.println(contador);
            contador++;
        }
    }
}
```

## Salida Esperada
```
0
1
2
3
4
```
