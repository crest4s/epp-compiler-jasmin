# epp-compiler-jasmin

Compiler for **E++**, a small Spanish-keyword programming language, built with ANTLR4 and Java. It performs lexical, syntactic and semantic analysis and generates JVM bytecode in [Jasmin](https://jasmin.sourceforge.net/) assembly, which is then assembled into `.class` files and run on the JVM. The project also includes a CSV-to-JSON translator with semantic validation.

Lab project (PL3) for the *Procesadores del Lenguaje* (Language Processors) course at the University of Alcalá (UAH), 2025–26 academic year. It builds on the grammars from [antlr4-parsers-lab](https://github.com/crest4s/antlr4-parsers-lab).

## The E++ language

```
# Variable initialisation
asignar a = 20 ;P

# if-else
a > 2 ???
si ->
    a = 5 - 2 ;P
terminar

# print
mostrar a ;P
```

Supported constructs (see `compilador/src/main/antlr4/epp/`): variable declaration and assignment (`asignar`), output (`mostrar`) and input (`leer`), `mientras` (while) loops, `para ... desde ... hasta ... paso` (for) loops, conditionals (`si` / `no`), blocks closed with `terminar`, comments (`#`), arithmetic, comparison and boolean expressions (`AND`, `OR`, `NOT`, `verdadero`, `falso`).

## Pipeline

1. **Lexer and parser** — `EPPLexer.g4` / `EPPParser.g4`, generated by the ANTLR4 Maven plugin.
2. **Semantic analysis** — `EPPSemanticListener`: variables used without (or before) being declared, and division or modulo by a literal zero. Errors are reported with line and column.
3. **Code generation** — `EPPToJasminVisitor` walks the parse tree and emits a Jasmin `.j` file next to the input (`EPPCompilerCLI`).
4. **Assembly** — Jasmin turns the `.j` file into a `.class` file that runs with `java`.

The CSV module (`compilador/src/main/java/csv/`) parses CSV files, reports every semantic error found (`CSVSemanticListener`) and converts valid files to JSON (`CSVToJsonVisitor`).

## Project structure

```
compilador/                 # Maven project (ANTLR4 grammars + Java sources)
pruebas/
├── csv/                    # CSV inputs, including one with errors
└── epp/
    ├── basico/, avanzado/  # E++ programs
    ├── jasmin/             # programs used to test code generation
    └── errores/            # lexical, syntactic and semantic error cases
jasmin/ejemplos-manuales/   # hand-written Jasmin examples (if, loops, functions...) with notes
scripts/                    # test runners
```

## Requirements

- JDK 25 (the `pom.xml` targets Java 25) and Maven
- **Jasmin 2.4**, not included in this repository. Download `jasmin-2.4.zip` from <https://sourceforge.net/projects/jasmin/files/> and extract it so that the jar is at `jasmin/herramientas/jasmin-2.4/jasmin.jar` (the path used by the test scripts).

## Usage

```bash
cd compilador
mvn compile

# E++ -> Jasmin (.j is written next to the input file)
mvn exec:java -Dexec.mainClass="epp.EPPCompilerCLI" -Dexec.args="../pruebas/epp/basico/E++.txt"

# Jasmin -> .class, then run it
java -jar ../jasmin/herramientas/jasmin-2.4/jasmin.jar ../pruebas/epp/basico/E++.j
java <ClassName>

# CSV -> JSON (asks for the CSV path)
mvn exec:java -Dexec.mainClass="csv.CSVMain"
```

The scripts in `scripts/` automate the three steps for every test case. They use paths relative to `compilador/`, so run them from there, for example `bash ../scripts/test_basico.sh`.
