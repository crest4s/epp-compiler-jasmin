# Ejemplos de Referencia

Esta carpeta contiene ejemplos de referencia proporcionados por el profesor para aprender el uso de ANTLR y visitores.

## Contenido

### `/demo-profesor`
Ejemplos de demostración del profesor que muestran:
- **Demo.g4** - Gramática de ejemplo
- **Main.java** - Programa principal de ejemplo
- **MyVisitor.java** - Implementación de un visitor personalizado
- **code.demo** - Código de prueba para la gramática Demo
- **HolaMundo.j** - Ejemplo de código Jasmin "Hola Mundo"
- **Sumar.j** - Ejemplo de código Jasmin con suma
- **Vacio.j** - Ejemplo de código Jasmin de programa vacío

## Propósito

Estos ejemplos sirven como:
- Material de aprendizaje para entender ANTLR
- Referencia para implementar visitors
- Ejemplos básicos de código Jasmin
- Guía para la estructura del proyecto

## Nota

Los ejemplos de Jasmin aquí son versiones simplificadas. Para ejemplos completos y documentados de la **Parte 2** del proyecto, consulta la carpeta `/jasmin/ejemplos-manuales/`.
