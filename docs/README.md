# Documentación

Esta carpeta contiene toda la documentación del proyecto.

## Contenido

### `Enunciado_Practica3.pdf`
Enunciado oficial de la Práctica 3 de Procesadores del Lenguaje.

**Contenido del enunciado:**
- Parte 1: CSV a JSON (2.5 puntos)
- Parte 2: Ejemplos Jasmin manuales (2.5 puntos)
- Parte 3: Compilador E++ completo (5 puntos)
  - Nivel básico (1.5 puntos)
  - Nivel intermedio (3.5 puntos)

### Memoria del Proyecto *(pendiente)*
La memoria debe incluir:
- Explicación de las decisiones de diseño
- Descripción de la tabla de símbolos
- Sistema de gestión de errores
- Proceso de generación de código Jasmin
- Conjunto de pruebas y validación
- Resultados de ejecución
